# The Cat in the Hat — English Learning Unit

An original, classroom-ready English Language Teaching mini-site for Grade 3 learners (ages 9–10), inspired by Dr. Seuss's *The Cat in the Hat*.

## What's included
- Four 55-minute lesson plans
- Learning objectives, target language, materials and assessment
- Vocabulary practice and a present-continuous quiz
- A sentence builder and mini-story writing prompt
- Differentiation and inclusion suggestions
- Teacher-facing assessment rubric

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. After GitHub finishes publishing, the Pages URL will appear in that section.
